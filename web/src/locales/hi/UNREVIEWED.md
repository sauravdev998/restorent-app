# Hindi: not yet reviewed by a native speaker

Every file in this folder was machine translated. The Devanagari is real, the keys are complete,
and the plural forms are right, which is what this folder exists to prove: script, string length,
and layout all behave under a language that is not English.

The wording is provisional. It is understandable rather than good, and some of it is certainly
stiffer than a person would write.

**Before launch**, a native speaker needs to read it, with particular attention to:

- **The kitchen words.** They are read at a glance, under pressure, from across a hot room. Short
  and unambiguous beats literal every time.
- **The status words** (`status.*`). Five words that a chef and a waiter act on hundreds of times
  a shift.
- **The failure sentences** (`error.*`, `language.*`, `system.*`). Somebody reads these when
  something has already gone wrong, so they have to say plainly what happened and what to do.

Delete this file when that pass is done.
